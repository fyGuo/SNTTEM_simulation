Simulation Design: Overlapped vs. Non-overlapped Population Comparison

1. Estimation target

We work with three decision points. The treatments are \(A_0, A_1, A_2\), the time-varying covariates are \(L_0, L_1, L_2\), and the (normally distributed) outcome is \(Y\). Potential outcomes are written \(Y^{a_0,a_1,a_2}\).

We posit two structural nested mean (blip) models:

  1. Time-2 blip — effect of the last treatment given history \(\bar S_2\): \[ \mathbb{E}\!\left(Y^{a_0,a_1,1} - Y^{a_0,a_1,0}\mid \bar S_2\right)=\gamma_2(\bar S_2). \]

  2. Time-1 blip — effect of \(A_1\) holding \(A_2\) at its reference regime \(h_2^1\) (here: \(A_2 = 0\)), given history \(\bar S_1\): \[ \mathbb{E}\!\left(Y^{a_0,1,h_2^1} - Y^{a_0,0,h_2^1}\mid \bar S_1\right)=\gamma_1(\bar S_1). \]

Under sequential randomization, the target contrast \(\mathbb{E}\!\left(Y^{0,1,0} - Y^{1,1,0}\mid L_0\right)\) admits the identifying expression

\[ \begin{aligned} \mathbb{E}\!\left(Y^{0,1,0} - Y^{1,1,0}\mid L_0\right) =\;& \underbrace{\mathbb{E}\!\left[\frac{1-A_0}{1-\pi_0(L_0)}\, \frac{A_1}{\pi_1(\bar S_1)}\bigl\{Y - A_2\gamma_2(\bar S_2)\bigr\}\;\middle|\;L_0\right]}_{\text{non-overlapped population } (A_0=0)} \\[4pt] &-\underbrace{\mathbb{E}\!\left[\frac{A_0}{\pi_0(L_0)}\bigl\{Y - A_2\gamma_2(\bar S_2) - (A_1-1)\gamma_1(\bar S_1)\bigr\}\;\middle|\;L_0\right]}_{\text{overlapped population } (A_0=1)}. \end{aligned} \]

Here the propensity scores are \[ \pi_0(L_0)=\Pr(A_0=1\mid L_0),\qquad \pi_1(\bar S_1)=\Pr(A_1=1\mid \bar S_1),\qquad \pi_2(\bar S_2)=\Pr(A_2=1\mid \bar S_2). \]

History summaries used below. We take \[ \bar S_1 = (L_0, A_0, L_1), \qquad \bar S_2 = (L_0, A_0, L_1, A_1, L_2). \]

2. Data-generating mechanism

Variables are generated in temporal order \(L_0 \to A_0 \to L_1 \to A_1 \to L_2 \to A_2 \to Y\).

Let \(\operatorname{expit}(x)=1/(1+e^{-x})\).

Baseline

\[ L_0 \sim \mathcal{N}(0,1),\qquad A_0 \mid L_0 \sim \text{Bernoulli}\bigl(\pi_0(L_0)\bigr),\quad \pi_0(L_0)=\operatorname{expit}(\alpha_{00}+\alpha_{01}L_0). \]

Time 1

\[ L_1 \mid L_0,A_0 \sim \mathcal{N}\bigl(\lambda_{10}+\lambda_{11}L_0+\lambda_{12}A_0,\ \sigma_{L_1}^2\bigr), \] \[ A_1 \mid \bar S_1 \sim \text{Bernoulli}\bigl(\pi_1(\bar S_1)\bigr),\quad \pi_1(\bar S_1)=\operatorname{expit}(\alpha_{10}+\alpha_{11}L_0+\alpha_{12}A_0+\alpha_{13}L_1). \]

Time 2

\[ L_2 \mid \bar S_1,A_1 \sim \mathcal{N}\bigl(\lambda_{20}+\lambda_{21}L_1+\lambda_{22}A_1+\lambda_{23}A_0,\ \sigma_{L_2}^2\bigr), \] \[ A_2 \mid \bar S_2 \sim \text{Bernoulli}\bigl(\pi_2(\bar S_2)\bigr),\quad \pi_2(\bar S_2)=\operatorname{expit}(\alpha_{20}+\alpha_{21}L_1+\alpha_{22}A_1+\alpha_{23}L_2). \]

Note \(L_2\) is a time-2 confounder affected by prior treatment \(A_1\) (treatment–confounder feedback), the feature that makes the problem non-trivial.

Outcome (structural nested model form)

To make the blip models hold exactly with a known truth, generate \(Y\) additively from the blips:

\[ Y = \underbrace{\beta_0+\beta_1 L_0+\beta_2 A_0+\beta_3 L_1}_{\text{treatment-free mean } h(L_0,A_0,L_1)} \;+\; \gamma_1(\bar S_1)\,A_1 \;+\; \gamma_2(\bar S_2)\,A_2 \;+\;\varepsilon, \qquad \varepsilon\sim\mathcal{N}(0,\sigma_Y^2), \]

with linear blip functions \[ \gamma_1(\bar S_1)=\psi_{10}+\psi_{11}L_1,\qquad \gamma_2(\bar S_2)=\psi_{20}+\psi_{21}L_2 . \]

Key modeling choice: the treatment-free mean \(h\) does not depend on \(L_2\). Because the time-1 blip sets \(A_2=0\) (its \(\gamma_2\) term vanishes), this guarantees the time-1 blip equals \(\gamma_1(\bar S_1)\) with no contamination from the \(A_1\!\to\!L_2\) feedback path, while \(L_2\) still acts as a genuine time-2 confounder (it drives \(\pi_2\) and scales the \(A_2\) effect).

3. Why the blip models hold

Since \(\varepsilon\) is independent additive noise and treatments are sequentially randomized given the observed past:

  • Time 2. \(L_2\) (and thus \(\bar S_2\)) is fixed before \(A_2\), so \[ Y^{a_0,a_1,1}-Y^{a_0,a_1,0}=\gamma_2(\bar S_2)\quad\text{(holds conditionally). }\checkmark \]

  • Time 1 with \(A_2=0\). With \(h\) free of \(L_2\), \[ Y^{a_0,1,0}-Y^{a_0,0,0}=\gamma_1(\bar S_1).\quad\checkmark \]

4. Closed-form truth for the target contrast

Let \(L_1^{a_0}=\lambda_{10}+\lambda_{11}L_0+\lambda_{12}a_0+\eta_1\) denote the counterfactual time-1 covariate (same noise draw \(\eta_1\) across regimes). Plugging in:

\[ Y^{0,1,0}-Y^{1,1,0} = \bigl[h(L_0,0,L_1^{0})-h(L_0,1,L_1^{1})\bigr]+\bigl[\gamma_1(\bar S_1^{0})-\gamma_1(\bar S_1^{1})\bigr]. \]

With the linear specification this simplifies to a constant:

\[ \boxed{\;\mathbb{E}\!\left(Y^{0,1,0}-Y^{1,1,0}\mid L_0\right) = -\bigl(\beta_2+\beta_3\lambda_{12}+\psi_{11}\lambda_{12}\bigr).\;} \]

(It is independent of \(L_0\) under this linear DGM; add an \(A_0\times L_0\) term in \(h\) if an \(L_0\)-varying truth is desired.)

5. Default parameter values

Group Parameters Values
\(\pi_0\) \(\alpha_{00},\alpha_{01}\) \(0.0,\ 0.5\)
\(L_1\) \(\lambda_{10},\lambda_{11},\lambda_{12},\sigma_{L_1}\) \(0.0,\ 0.6,\ 0.5,\ 1.0\)
\(\pi_1\) \(\alpha_{10},\alpha_{11},\alpha_{12},\alpha_{13}\) \(0.0,\ 0.3,\ 0.4,\ 0.5\)
\(L_2\) \(\lambda_{20},\lambda_{21},\lambda_{22},\lambda_{23},\sigma_{L_2}\) \(0.0,\ 0.6,\ 0.5,\ 0.3,\ 1.0\)
\(\pi_2\) \(\alpha_{20},\alpha_{21},\alpha_{22},\alpha_{23}\) \(0.0,\ 0.3,\ 0.4,\ 0.5\)
\(h\) \(\beta_0,\beta_1,\beta_2,\beta_3\) \(1.0,\ 0.5,\ 1.0,\ 0.8\)
\(\gamma_1\) \(\psi_{10},\psi_{11}\) \(0.5,\ 0.7\)
\(\gamma_2\) \(\psi_{20},\psi_{21}\) \(0.4,\ 0.6\)
noise \(\sigma_Y\) \(1.0\)

With these values the true contrast is \[ -\bigl(\beta_2+\beta_3\lambda_{12}+\psi_{11}\lambda_{12}\bigr) = -\bigl(1.0+0.8\cdot0.5+0.7\cdot0.5\bigr) = -1.75 . \]

6. Simulation plan

  1. Generate \(N\) i.i.d. subjects from Section 2 (e.g. \(N=2000\)).
  2. Fit nuisance models (or use the true ones for an oracle check):
    • \(\pi_0(L_0)\), \(\pi_1(\bar S_1)\) via logistic regression;
    • blip functions \(\gamma_1,\gamma_2\) via g-estimation / known truth.
  3. Form the two IPW/g-estimation terms in Section 1.
  4. Estimate \(\mathbb{E}(Y^{0,1,0}-Y^{1,1,0}\mid L_0)\) (e.g. project onto \(L_0\), or report the marginal average since the truth is constant here).
  5. Repeat over \(R\) Monte Carlo replications; report bias, empirical SE, and coverage against the truth \(-1.75\).

Oracle sanity check: plug the true \(\pi_0,\pi_1,\gamma_1,\gamma_2\) into the estimator — the sample mean of each population term, differenced, should converge to \(-1.75\).
